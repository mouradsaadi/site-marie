# Marie E. Robin

Static academic website built with React and Vite.

## Local development

```sh
npm install
npm run dev
```

## Production

`npm run build` creates the static site in `dist/`. GitHub Actions deploys it to GitHub Pages on pushes to `main`. The production domain is [marieerobin.com](https://marieerobin.com).

Edit site content in `src/content.js`.
